# 采集范围与 MOF 视觉基线的匹配

更新：2026-11-06。本文是项目工作范围与方案草案，不代表所有采集器已经实现。

## 统一任务

对指定实验对象记录状态，识别有意义的变化，输出对象身份、发生时间、状态或数值、
数据来源、质量标记及证据。化学原因与是否符合 SOP 需要结合操作上下文进一步判断。

## 首批五个工作包

| 工作包 | 要记录的信息 | 拟采用的采集方式 | 输出示例 | 当前 MOF 权重覆盖 |
|---|---|---|---|---|
| 1. 容器内可见物态 | 澄清/浑浊、可见固体出现/消失、残留；后续气泡、泡沫、颜色、分层、液位 | 清晰容器近景 + 专用视觉算法 | 可见固体首次出现的时间区间及证据帧 | 覆盖均相、非均相、固体、残留、空余区域；不覆盖气泡等独立类别 |
| 2. 温度 | 实测值、测量位置、设定值（区分记录） | 仪器接口或温度探头；必要时屏幕 OCR | 反应液温度曲线、达到阈值事件 | 无 |
| 3. pH | pH 实测值、稳定/有效状态 | 适用的 pH 仪接口或屏幕 OCR | pH 时间序列、跨阈值变化 | 无 |
| 4. 质量（俗称重量） | 质量、单位、稳定标记、去皮状态 | 天平接口或屏幕 OCR | 某次称量的稳定结果 | 无 |
| 5. 通用仪器读数接入 | 转速、压力、电导率及无法直读设备的显示值，按实验决定 | 数字接口、协议解析、专用 OCR | 带设备 ID 和测量语义的读数记录 | 无 |

仪器读数是采集渠道，也可以承载温度、pH、质量；它们不应被重复统计为独立信息。
保留第五工作包是为了单独建设通用设备接入/OCR能力。
视频中的浑浊外观不是校准的浊度数值；可见固体不是晶体结构或化学身份。

所有数据共有字段建议：experiment_id、object_id、source_id、timestamp、signal、
value/label、unit、quality、evidence。quality 区分有效、遮挡、不可读、断流；
数字接口没有模型置信度时不得虚构 confidence。

## 论文与现有实现的匹配

- 论文链接：https://doi.org/10.1039/D5DD00384A
- MOF 应用：https://pmc.ncbi.nlm.nih.gov/articles/PMC13308677/
- 作者数据：https://zenodo.org/records/16209653
- 作者代码：https://github.com/AccelerationConsortium/CV-HTE-Tutorial

教程介绍受控拍摄下的两级容器/物态检测，并非覆盖整张实验台的通用实验理解。
应用论文将不同时间点的图像检测用于首次可见浑浊/固体的时间分析；结构确认另用表征。
因此直接匹配工作包1的一部分。我们的传感器采集、多流同步、气泡类别、
持续对象身份、变化判定和文字解释仍需独立建设。

## 当前验证的正确顺序

1. 核实作者原始数据与标注格式、类别编号、发布划分。
2. 使用现有权重对作者独立数据推理；不训练，不为获得更好测试结果调阈值。
3. 将固定阈值检测结果与发布标注对应，报告精确率、召回率及定位标准；
   若使用与论文不同的数据划分/裁剪/指标，应明确不能称为论文表格的严格复现。
4. 分离原始全图两级推理与已知容器区域的物态推理，定位误差来源。
5. 再选择内容物清楚的本地或集群视频，补人工状态及时间标注，评估迁移。

训练包上的成绩只能作运行及拟合检查。作者用户研究数据若确与训练独立，
更适合检验公开权重的应用效果；公开标注和权重是否完全对应必须通过实际清点确认。
