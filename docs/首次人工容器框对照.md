# 首次人工容器框对照

日期：2026-11-06。视频：`data/videos/飞书20261106-111753.mp4`。

## 方法

在0、15、30、45、60、75、90秒检查两只真实容器，合计14个区域。
A为左侧较大的透明容器，B为其右下的小圆形容器。
助手直接查看原始画面与放大裁剪，手工指定原画面坐标框，并记录遮挡及可判读性；
不是用检测模型生成这些框。所选时间点的容器位置允许复用同一框，未将其外推为全视频轨迹。

标注保存在 `annotations/first-video-manual.json`，这是助手视觉初标，尚未经实验人员复核。
使用 `scripts/run_manual_roi.py` 跳过容器模型，仅运行原始 phase.pt；
保持 imgsz=640、conf=0.3、iou=0.1，与原自动流程一致。

```powershell
.\.venv\Scripts\python.exe scripts/run_manual_roi.py annotations/first-video-manual.json --output outputs/manual-roi-new-run
```

## 观察与结果

| 时间（秒） | 容器A预测 | 容器B预测 |
|---|---|---|
| 0 | 无检测 | 无检测 |
| 15 | Hetero 0.499 | 无检测 |
| 30 | Hetero 0.594 | 无检测 |
| 45 | Hetero 0.521 | 无检测 |
| 60 | Hetero 0.595 | 无检测 |
| 75 | Hetero 0.392 | 无检测 |
| 90 | 无检测 | 无检测 |

无检测只表示没有超过阈值的输出，不表示空容器或正确拒答。
这些置信度不是正确率。

A约71×68像素，透明容器与背景混叠，缺少可靠液面或内容物状态证据；
B仅约42×42像素，浅色区域无法可靠区分为固体、非均相液体、反光或其他材料。
因此14个区域的 phase_gt 均为 null，scorable 均为 false，不能计算物态准确率。
示例15秒的Hetero框主要落在A的瓶口附近，不能据此确认整个容器中的液体为非均相。

在这14个选定区域上，以IoU≥0.5匹配原自动容器框，共6个有匹配（A的15–75秒共5个，B的45秒1个）。
这仅为所选目标的框对应统计，不是全视频检测mAP或整体召回率。
15、30、75秒的A在自动框裁剪下无物态输出，人工框裁剪后出现Hetero，
说明输出对裁剪范围敏感，但缺少真值，不能判断变化是否意味着更准确。

## 结论与下一步

两级流程已成功拆开；指定正确容器并未提供足以确认可靠物态判断的结果。
当前瓶颈包括目标分辨率、俯视观察条件、遮挡，以及训练场景与当前视频的差异。
本实验不能单独判定模型本身的准确率，也不能证明只修复容器定位就足够。
下一步应优先从集群中选择内容物可判读的近景原始视频，由实验人员复核状态标签，
再用同样的容器ROI推理流程评测。不要把画面上采样放大当成获得更多真实细节。

输出目录：`outputs/manual-roi-first-video`。
其中 `overview.jpg` 是结果总览，`predictions.jsonl` 是完整推理记录，
`summary.csv` 是逐区域结果，`comparison.csv` 是与自动框的对应比较。
